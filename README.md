# Interframe Rec — descargas

Instaladores y actualizaciones de **Interframe Rec**, el grabador de partidas hecho por CodigoF sobre la base de [Segra](https://github.com/Segergren/Segra) (GPL-2.0).

## Instalar en una PC nueva

1. Entrá a [Releases](../../releases/latest) y bajá `InterframeRec-win-Setup.exe`.
2. Abrilo. Se instala solo, sin pedir permisos de administrador, y trae todo lo necesario: .NET, OBS y la interfaz. Si a la PC le faltan WebView2 o Visual C++ 2015-2022, los instala también.
3. Windows puede mostrar «Windows protegió su PC» porque el instalador no está firmado con un certificado comercial: tocá **Más información → Ejecutar de todas formas**.

Requisitos: Windows 10 u 11 de 64 bits.

## Actualizaciones

La app instalada revisa este repositorio y se actualiza sola. Cada paquete se verifica con su hash SHA-256 antes de aplicarse, y solo se aceptan paquetes de Interframe Rec.

El código fuente vive en un repositorio privado.
